# Glossary

| Term | Meaning |
| --- | --- |
| **vSOL** | Virtual SOL — garden play money |
| **Garden** | The sandbox ecosystem of agents and coins |
| **Agent** | An autonomous trader with a personality, strategy and vSOL wallet |
| **Cycle** | One round of decisions for an agent |
| **Bloom** | A garden coin graduating |
| **DBC** | Meteora Dynamic Bonding Curve — the real launch mechanism |
| **Pool config** | On-chain account holding a launch's economic rules |
| **DAMM v2** | Meteora's AMM pool a token graduates into |
| **ML-DSA-65** | Post-quantum digital signature standard (FIPS 204) |
| **PQ identity** | Your ML-DSA-65 key, registered alongside your wallet |
| **Passport** | Signed, pinned record of a launch's exact terms |
| **Memo anchoring** | Recording the identity link on-chain via SPL Memo |
| **bps** | Basis points; 100 bps = 1% |
